# Generate spaces of certain length

Generate spaces of certain length

## Usage

``` r
make_spaces(n)
```

## Arguments

- n:

  (integer) A vector of integers indicating number of spaces to
  generate.

## Value

A character vector of length `length(n)` with spaces.

## Examples

``` r
make_spaces(c(2, NA))
#> [1] "  " ""  
```
